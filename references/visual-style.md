# 默认视觉风格

项目未提供新画风时采用以下文字。具体主题的场景细节由页面规划决定；不将餐厅家具、服装等复制到所有主题。

【整体画风】3:4竖版，建议1536×2048像素。细腻彩色铅笔手绘，融合半写实日系生活漫画与复古绘本插画。保留彩铅排线、细小颗粒、米白纸张纹理，局部叠加轻薄水彩晕染。画面精致、温暖，面向成人英语学习者。

【人物表现】年轻成年人，接近真实人体比例，五官带日系漫画的柔化处理，眼睛大小适中，笑容和动作自然。头发有细密深棕色笔触；衣服有织物纹理、褶皱和柔和阴影。轮廓为细棕灰线条。同一人物在不同画面中的发型、服装和面部特征一致。

【配色与光线】暖米白和奶油色为底，搭配蜂蜜金、浅赭、木棕、鼠尾草绿及少量藏蓝。低饱和暖色，保留适度明暗对比；自然日光与室内暖黄灯光交融。木材、布料、植物和食物有细致手绘质感。

【场景构图】按本页故事安排一个主场景或多个连续画面，视觉主体明确。多个画面以米白留白、渐淡彩铅笔触和不规则边缘自然衔接，不画粗黑分格框。背景靠近主体时较清晰，边缘逐渐淡入纸张。环境细节贴合主题，为词条留出空白。

【标题设计】顶部大号深棕色中文毛笔手写标题，笔画厚实、书写感自然。两侧少量手绘绿叶，下方细长绿色铅笔线。副标题置于浅赭黄色横向彩铅涂抹底纹上，中英文居中，字迹清楚。

【词汇标签】英文用深藏蓝粗体衬线字体，背后为浅绿、浅蓝、淡粉、浅紫或奶油黄的不规则圆角手绘底纹，仅衬英文。下方依次为黑色音标、词性与中文；音标为清晰衬线字体，中文近似宋体。英文最大，三行层级稳定，手机查看仍可辨认。

【箭头与排版】标签靠近目标，使用短而柔和的灰蓝曲线箭头，带细白描边，落点明确，不穿文字、脸部或其他标签。评价、动作或抽象词按页面说明使用情境表达，不强行指向单个物体。词条只出现一次，四周留安全边距。

【完成观感】整页像精心绘制的纸质英语学习插画，人物、环境与教学标注融为一体。文字严格采用本页清单，不自行补充释义。
